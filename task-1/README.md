Новые компоненты и их роль:
1) Ключевым сервисом обновленного архитектурного решения будет API gateway, этот компонент выполняет роль
гейтвей и backend for frontend. Ведёт все OAuth-обмены с Identity Broker (получает внутренные токены).
Фронтенду даёт только HttpOnly Secure cookie, таким образом решает задачу безопасной схемы работы с access- и refresh-токенами, 
которая исключает передачу фронтенду токенов, которые были получены от IdP.
Вызывает внутренние API (Resource Server), используя серверные токены. Все запросы от web, mobile идут в систему через API gateway с проверкой токенов.

2) IdP (identity providers) - локальные удостоверяющие центры в различных странах

3) Identity Broker (keycloak) - Подключается к внешним IdP, выпускает внутренные токены (JWT) для BionicPRO, при этом исходные токены IdP остаются внутри брокера.
